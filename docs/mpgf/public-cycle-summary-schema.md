# MPGF Public Cycle Summary Schema

Schema file: `config/mpgf/public-cycle-summary.schema.json`

The public summary exposes:

- `releasedInternalCents`
- `payoutAuthorizedCents`
- `externallyPaidCents`
- non-real-money pledge totals
- allocation/disbursement disclaimers

In direct-working demo mode, released, authorized, and externally paid fields must remain zero.
