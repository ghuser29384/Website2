# MPGF Completion Profile Evidence Schema

Schema file: `config/mpgf/completion-profile-evidence.schema.json`

Profiles:

- `demo_complete`
- `exact_pilot_complete`
- `real_money_complete`

Production-domain `demo_complete` evidence must include production deployment target validation, production deployment prerequisite validation, production direct-working launch, www smoke-test profile validation, www direct-working verification, auth/session verification, public-experience verification, participant-journey verification, production health check, and completion-gate deployment environment validation.
