Thresholds

Each threshold defines a funding tranche. If a threshold is not reached, only money above the previous reached threshold is refunded with the failure bonus.

1 of 10 thresholds

Example: with thresholds of $1,000 and $5,000, raising $3,000 reaches the first threshold. The $2,000 above $1,000 is refunded with the selected failure bonus because the $5,000 threshold was not reached.
